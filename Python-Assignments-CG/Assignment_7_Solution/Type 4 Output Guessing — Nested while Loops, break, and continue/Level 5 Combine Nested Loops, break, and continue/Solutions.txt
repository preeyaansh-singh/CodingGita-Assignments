Q77. Skip One Value, Then Break
Code execution:

For each value of i, the inner loop works as follows:
- j = 1 → prints.
- j = 2 → continue skips the print statement.
- j = 3 → prints.
- j = 4 → break terminates the inner loop.
This repeats for both i = 1 and i = 2.

Predicted output:
1 1
1 3
2 1
2 3


Important concept:
- continue skips the current iteration.
- break terminates the current loop completely.
