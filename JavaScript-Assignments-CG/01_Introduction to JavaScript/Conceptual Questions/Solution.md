## Q14. Static vs Dynamic Website

**Static Website:**
- Fixed content, same for every user
- No real-time updates
- **Example:** Portfolio website or simple landing page

**Dynamic Website:**
- Content changes based on user input or data
- Uses backend + database
- **Example:** Instagram, Amazon, or any e-commerce site


## Q15. Two Features of JavaScript

1. **Interactivity:**  
   JavaScript allows actions like button clicks, form validation, sliders, etc.

2. **DOM Manipulation:**  
   It can change HTML/CSS dynamically without reloading the page (e.g., updating text, showing/hiding elements)

## Q17. Internal vs External JavaScript

**Inside HTML (`<script>` tag):**
- Code is written directly inside the HTML file

**External `.js` file:**
- Code is written in a separate file and linked to HTML

**Advantages of External JS:**
- Code is reusable across multiple pages  
- Cleaner and more organized code  


## Q18. Frontend vs Backend (Restaurant Analogy)

- **Customer (User):** Places the order (interacts with UI)
- **Waiter (Frontend):** Takes order and shows food (handles UI interaction)
- **Chef (Backend):** Prepares the food (processes logic, works with data)

👉 Frontend = what user sees and interacts with  
👉 Backend = what happens behind the scenes
