# JavaScript – Answers

---

## Q1. What is JavaScript?
JavaScript is a high-level, interpreted programming language used to make web pages interactive and dynamic (e.g., handling clicks, animations, form validation).

---

## Q2. Who created JavaScript and in which year?
JavaScript was created by Brendan Eich in 1995 at Netscape.

---

## Q3. What was the original name of JavaScript?
The original name of JavaScript was Mocha, later renamed to LiveScript, and finally JavaScript.

---

## Q4. Is JavaScript the same as Java? Give one major difference.
No, JavaScript is not the same as Java.  
Difference: Java is a compiled, strongly-typed language, while JavaScript is an interpreted, dynamically-typed language mainly used for web development.

---

## Q5. What does it mean when we say JavaScript is a high-level programming language?
It means JavaScript is easy to read and write because it hides complex details like memory management and hardware-level operations.

---

## Q6. Is JavaScript a compiled language or an interpreted language? Explain briefly.
JavaScript is primarily an interpreted language, meaning it runs line-by-line in the browser. Modern engines also use Just-In-Time (JIT) compilation for better performance.

---

## Q7. Name the JavaScript engines used by the following browsers:
- Google Chrome → V8  
- Mozilla Firefox → SpiderMonkey  
- Apple Safari → JavaScriptCore (Nitro)

---

## Q8. What is Dynamic Typing in JavaScript?
Dynamic typing means you do not need to declare data types explicitly, and a variable can change its type during execution.

Example:
```js
let x = 10;      // number
x = "Hello";     // now string
```
---
## Q9. Static vs Dynamic Website

**Static Website:**
- Displays fixed content (same for every user)
- Built using HTML & CSS only
- No real-time updates or database

**Dynamic Website:**
- Content changes based on user interaction or data
- Uses JavaScript, backend, and databases
- Example: login systems, dashboards, e-commerce


## Q10. Three Pillars of Front-End Web Development

- **HTML (Structure):** Defines the structure of a webpage  
- **CSS (Style):** Controls design and layout  
- **JavaScript (Behavior):** Adds interactivity  


## Q11. Frontend vs Backend

**Frontend:**
- User interface (what users see)
- Built using HTML, CSS, JavaScript

**Backend:**
- Server-side logic (works behind the scenes)
- Handles database, authentication, APIs


## Q12. What is Node.js?

- Node.js is a runtime environment that runs JavaScript outside the browser
- Used to build servers and backend applications


## Q13. ECMAScript & JavaScript

- ECMAScript is the standard/specification for JavaScript
- JavaScript follows the rules defined by ECMAScript
- Simple: ECMAScript = rules, JavaScript = implementation
