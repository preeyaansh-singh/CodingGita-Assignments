## 8. Predict the Output
- undefined undefined
- object null
- number 42
- string Hello
- boolean true
- symbol Symbol(key)
- bigint 123n

### Explanation:
- a → declared but not assigned → undefined
- b → explicitly assigned null → type shows "object" (JS quirk)
- c → number → "number"
- d → string → "string"
- e → boolean → "boolean"
- f → symbol → "symbol" (unique identifier)
- g → BigInt → "bigint" (used for large integers)
