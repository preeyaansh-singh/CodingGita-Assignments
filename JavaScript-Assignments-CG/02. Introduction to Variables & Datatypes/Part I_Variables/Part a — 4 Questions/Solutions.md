## JavaScript Variable Practice

### 1. Personal Information
```js
let name = "Preeyaansh";
let age = 18;
let city = "Kalol";

console.log(name);
console.log(age);
console.log(city);
```
### 2. Change the Score
```js
let score = 50;
score = 80;

console.log(score);
```
### 3. Constant Value
```js
const PI = 3.14;

console.log(PI);
```
### 4. Uninitialized Variables
```js
var num1;
let num2;

console.log(num1); // undefined
console.log(num2); // undefined

num1 = 10;
num2 = 20;

console.log(num1);
console.log(num2);
```
